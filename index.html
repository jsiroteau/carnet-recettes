Règles de bonne conduite

  1. Compléter plutôt que remplacer. Préciser une quantité ou une étape, oui. Effacer la recette d'un autre, non.
  2. Écrire les étapes à l'infinitif, en répétant les quantités — « Ajouter 250g de farine » et non « Ajouter la farine ». C'est ce qui permet au schéma de se construire.
  3. Lister les ingrédients dans l'ordre où ils servent.
  4. Relire le schéma après avoir changé le déroulé : les deux doivent raconter la même chose.
  5. Rien n'est perdu. L'historique est conservé, une maladresse se rattrape toujours.

Où trouver le jeton d'accès ?

Le jeton est un mot de passe délivré par GitHub pour autoriser cette application à écrire dans le dépôt. Il faut être connecté à GitHub sur cet appareil.

  1. Ouvrir github.com/settings/personal-access-tokens/new
  2. Token name : ce que l'on veut, par exemple « carnet de recettes ».
  3. Expiration : au choix. Au-delà de la date, en refaire un.
  4. Repository access : cocher Only select repositories, puis choisir le dépôt du carnet.
  5. Permissions → Repository permissions → Contents → Read and write. C'est la seule permission nécessaire.
  6. Generate token, puis copier le jeton immédiatement : GitHub ne l'affiche qu'une fois.
  7. Le coller dans le champ ci-dessous, puis enregistrer.

Les jetons existants se retrouvent sur github.com/settings/tokens. Si une de ces adresses ne mène nulle part, partir de Settings (sous l'avatar, en haut à droite) puis Developer settings, tout en bas du menu de gauche.

Ces réglages n'existent que sur le site : depuis un téléphone, passer par le navigateur, parfois en demandant la version pour ordinateur.

Le nom exact tel qu'il figure dans l'adresse du dépôt, après la barre oblique — sans espaces ni accents.

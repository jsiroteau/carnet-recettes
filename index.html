Réglages

Pour ajouter des photos directement depuis l'application, elle a besoin d'un accès en écriture à votre dépôt GitHub. Ces informations restent uniquement sur cet appareil (jamais partagées ni envoyées ailleurs qu'à GitHub).

Déchiffrage des recettes photographiées

Pour lire une recette prise en photo, l'application a besoin d'une clé d'API Anthropic, que vous créez sur console.anthropic.com. Elle reste elle aussi uniquement sur cet appareil. Ne la mettez jamais dans votre dépôt GitHub : il est public.

Laissez tel quel sauf si le déchiffrage renvoie une erreur de modèle inconnu.

Modifier le carnet

Le carnet s'ouvre en lecture. Chacun peut le consulter et ajouter une recette avec le bouton ＋, mais corriger une recette existante demande d'activer le réglage ci-dessous. Il s'éteint à chaque fermeture de l'application.

Règles de bonne conduite

  1. Mettre à jour avant de modifier. Si l'accueil annonce de nouvelles recettes, chargez-les d'abord : sinon vous risquez d'effacer le travail de quelqu'un d'autre.
  2. Publier après avoir modifié. Tant que vous n'avez pas publié, votre ajout reste sur votre seul appareil.
  3. Compléter plutôt que remplacer. Préciser une quantité ou une étape, oui. Effacer la recette d'un autre, non.
  4. Écrire les étapes à l'infinitif, en répétant les quantités — « Ajouter les 250g de farine » et non « Ajouter la farine ». C'est ce qui permet au schéma de se construire.
  5. Lister les ingrédients dans l'ordre où ils servent.
  6. Relire le schéma après avoir changé le déroulé : les deux doivent raconter la même chose.
  7. Rien n'est perdu. L'historique est conservé, une maladresse se rattrape toujours.

Dépôt GitHub

Nécessaire pour publier et pour envoyer les photos. Ces informations restent sur cet appareil et ne sont transmises qu'à GitHub.

Comment obtenir un jeton d'accès ?

Le jeton est un mot de passe que GitHub vous délivre pour autoriser cette application à écrire dans le dépôt. Il faut être connecté à GitHub sur cet appareil.

  1. Ouvrir github.com/settings/personal-access-tokens/new
  2. Token name : ce que vous voulez, par exemple « carnet de recettes ».
  3. Expiration : au choix. Au-delà de la date, il faudra en refaire un.
  4. Repository access : cocher Only select repositories, puis choisir le dépôt du carnet.
  5. Permissions → Repository permissions → Contents → Read and write. C'est la seule permission nécessaire.
  6. Generate token, puis copier le jeton immédiatement : GitHub ne l'affiche qu'une fois.
  7. Le coller dans le champ ci-dessous, puis Enregistrer.

Vos jetons existants se retrouvent sur github.com/settings/tokens. Si une de ces adresses ne mène nulle part, partir de Settings (sous votre avatar, en haut à droite) puis Developer settings, tout en bas du menu de gauche.

Ces réglages n'existent que sur le site : depuis un téléphone, il faut passer par le navigateur, parfois en demandant la version pour ordinateur.
